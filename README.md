# Operating Systems: Three Easy Pieces - My Journey

## Introduction
This repository contains my journey and progress through the book [Operating Systems: Three Easy Pieces (OSTEP)](https://pages.cs.wisc.edu/~remzi/OSTEP/) by Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau. 

## Motivation
During my 2nd year of college, I took an operating systems class and genuinely enjoyed it. That is why I chose to dive deeper into the core mechanics of OS design. My goal is to solidify my understanding of OS's concepts. This repository serves as a personal archive of my study notes, code experiments, and homework solutions.
