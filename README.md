# My journey through learning Operating Systems

## Introduction
This repository contains my journey and progress through learning operating systems fundamentals. The base material (learning and practicing) for my journey is the [Operating Systems: Three Easy Pieces (OSTEP)](https://pages.cs.wisc.edu/~remzi/OSTEP/) book by Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau. For `hands-on experience` I use my university assignments from my [Operating Systems Course](https://cs-pub-ro.github.io/operating-systems/Assignments/).

## Motivation
During my 2nd year of college, I took an operating systems class and genuinely enjoyed it. That is why I chose to dive deeper into the core mechanics of OS design. My goal is to solidify my understanding of OS's concepts. This repository serves as a personal archive of my study notes, code experiments, and homework solutions.
